PIN security

PIN block formats

A PIN block is a structured representation of a PIN prepared for encryption; it is not the PIN itself and must remain protected as sensitive authentication data.

ISO 9564 formats

ISO 9564 defines multiple formats used by different payment flows. Commonly discussed formats include ISO-0, ISO-1, ISO-3 and ISO-4. ISO-0 incorporates a PAN-related block before encryption; the exact construction, cipher, padding and key usage must match the host specification. ISO-4 is associated with AES-based workflows and has different structure requirements.

Security boundaries

  • Do not log, persist, display, or transmit clear PINs.
  • Perform PIN translation and verification in an approved HSM boundary.
  • Use synthetic values and authorized test keys only.
  • Follow PCI PIN Security and scheme requirements in addition to protocol documentation.
