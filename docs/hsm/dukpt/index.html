DUKPT explained: BDK, IPEK and KSN

Derived Unique Key Per Transaction (DUKPT) limits the impact of a compromised transaction key by deriving a different key for each transaction.

The key terms

  • BDK: the base derivation key, held under strong control in the host/HSM domain.
  • IPEK: an initial PIN-encryption key injected into a device under approved controls.
  • KSN: the key serial number identifying the derivation context and transaction counter.

How the workflow fits together

The device advances a counter in the KSN and derives a transaction key; the host uses the BDK and received KSN to derive the corresponding key in an HSM. Algorithm variants, key usages and parity/format rules matter. Never expose production BDKs, IPEKs, PIN blocks or full KSN/key material in logs or test fixtures.
