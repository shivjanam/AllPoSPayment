Key management

TR-31 and TR-34 explained

TR-31 and TR-34 address different parts of secure payment-key lifecycle management; both require a governed HSM and key-management process.

TR-31 key blocks

TR-31 defines a structured key block that binds encrypted key material to a header describing attributes such as key usage and algorithm. The binding helps prevent key substitution and misuse. Correct interoperability depends on the key-block version, header fields, optional blocks, wrapping key and vendor implementation.

TR-34 remote key distribution

TR-34 describes a protocol for distributing symmetric keys using asymmetric cryptography and certificates. It is commonly discussed for remote initial key loading. Certificate validation, roles, transport, HSM policies and ceremony controls are as important as the cryptographic envelope.

Testing safely

Use non-production test keys, documented test certificates and your HSM vendor's command reference. Never turn a browser article into a key-ceremony procedure.
