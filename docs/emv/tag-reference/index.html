EMV tag reference

Tags are compact identifiers, not standalone explanations. Their meaning comes from the EMV book, kernel, scheme profile, and point in the transaction.

Common tags to recognize

  • 9F02 commonly represents the authorized amount in the transaction currency.
  • 9F26 carries an application cryptogram.
  • 9F27 conveys cryptogram information data.
  • 9F36 is the application transaction counter.
  • 95 is terminal verification results.
  • 9B is terminal transaction status information.

Use a reference responsibly

These examples help identify traces; they do not define what a terminal must send or an issuer must validate. Tags may be optional, conditionally required, proprietary, or subject to kernel and scheme rules. Always use the applicable EMV and integration documentation before implementing logic.
