BER-TLV

EMV TLV parser guide

BER-TLV encodes a tag identifier, a length, and exactly that many value bytes. Parsing it correctly means respecting boundaries before interpreting a tag.

Read TLV defensively

  1. Read the tag; EMV tags can span multiple bytes.
  2. Read the length; short and long-form lengths have different encodings.
  3. Consume precisely the declared value length.
  4. If the tag is constructed, parse its value as nested TLV only when the profile calls for it.

Field 55 is not a universal tag list

Hosts commonly carry EMV authorization data in ISO 8583 Field 55, but the required tags, order, encoding and whether a tag is request-only are contract-specific. Preserve raw bytes, validate their length, and avoid altering tags before an ARQC or MAC validation step.
