APDU simulator and smart-card testing

Application protocol data units (APDUs) are the commands and responses exchanged between a terminal and card application.

APDU basics

A command APDU commonly includes a class, instruction, parameters and optional data or expected response length. A response APDU contains optional data followed by status words. In EMV debugging, capture the complete sequence: SELECT, processing options, record reads and cryptogram-related commands have stateful relationships.

Trace method

  1. Identify the application and terminal/kernel profile.
  2. Preserve command and response bytes with timestamps and direction.
  3. Separate response data from status words, then decode BER-TLV where appropriate.
  4. Compare sequence and values with approved test cases, not just a single response.
