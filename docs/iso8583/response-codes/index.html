ISO 8583 Field 39 response codes

Field 39 communicates the result of processing, but its exact code set and terminal behavior are defined by the relevant network or host specification.

Interpret codes with context

Many environments use an approval value such as 00, and values that indicate a decline, a retry condition, a pickup instruction, or an issuer/system problem. Do not hard-code a generic list as a substitute for your acquirer or scheme mapping: private codes, display text, retry rules, and reversal requirements vary.

Test more than approval and decline

  • Verify user messaging and receipt behavior for each documented outcome.
  • Check whether the terminal must reverse after a timeout or ambiguous response.
  • Correlate Field 39 with the MTI, original data elements, and any network-specific fields.
  • Keep a versioned response-code matrix alongside your integration tests.
