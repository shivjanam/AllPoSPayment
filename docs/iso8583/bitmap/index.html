Field presence

ISO 8583 bitmap explained

A bitmap is a compact presence map. It tells the receiver which data elements to parse; it does not describe their length or meaning.

Primary and secondary bitmap

The primary bitmap represents the first set of field positions. In common ISO 8583 dialects, its first bit indicates that another bitmap follows; it is often described as the secondary bitmap indicator. Read it using the conventions in the integration guide, then parse only the fields whose corresponding bits are set.

Debugging a bitmap

  1. Confirm whether you have packed binary bytes or printable hexadecimal characters.
  2. Expand the bits from left to right without shifting for a header.
  3. List present fields and compare them with the actual message layout.
  4. When adding or removing a field in a test message, regenerate the bitmap and recheck any MAC coverage.

A bitmap mismatch shifts every subsequent element and can look like a field-length defect. Verify the presence map first.
