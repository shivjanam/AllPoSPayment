POS payment testing guide

A robust POS test plan connects card, terminal, gateway and host behavior—not just an approval response.

Coverage that matters

  • Purchase, reversal, refund, advice and any locally supported transaction types.
  • EMV contact/contactless paths and approved fallback behavior.
  • Online approval, decline, partial/ambiguous communication failure and recovery.
  • ISO 8583 field validation, including EMV Field 55 where applicable.
  • Receipt/UI behavior, duplicate prevention, audit trail and settlement lifecycle.

Test in layers

Use a simulator for deterministic host outcomes, then progress through partner and scheme certification environments. Log masked technical evidence and preserve correlation values such as STAN and retrieval reference. A local test tool supports engineering; formal certification still belongs to the relevant acquirer, payment scheme and lab.
